## 一、项目总览

**项目名称**：本地智能体（Local Agent）
**路径**：`D:/newwork/本地智能体`
**三栈架构**：
- 前端：Next.js 16.2.4 + React 19 + TypeScript + Tailwind CSS + shadcn/ui
- Gateway：Go 1.22+（控制平面，API 聚合，状态管理）
- Runtime：Rust（本地执行引擎，命令行/文件操作等）

**运行端口**：
- Gateway：`http://127.0.0.1:38471`（前端必须走此入口，独立前端服务器会导致 SSE 404）
- Runtime：`http://127.0.0.1:38472`
- MCP Server：`http://127.0.0.1:3344/mcp`（Rust MCP Server v0.2.0，20 个工具）
- MCP WebUI：`http://127.0.0.1:2233`

**构建命令**：
```powershell
# Gateway
cd gateway; go build -o gateway.exe ./cmd/server

# Frontend
cd frontend; npm run build   # 输出到 frontend/dist/
```

**重要规则（AGENTS.md）**：
- 用中文回答
- 单个函数不超过 30 行（按函数签名到结束右花括号连续计数）
- 不要给未修改的代码行添加注释
- 新增 Go 测试统一使用 testify
- 需要合并多个错误时优先使用 `errors.Join`
- Rust / Go / TS 源文件超过 600 行应评估拆分
- 临时目录 `tmp/` 下的实验目录应在 7 天内清理

## 二、已完成的核心工作

### 1. MCP 协议接入（已完成）

**当前状态**：Gateway 作为 MCP Client 聚合层，前端不直连 MCP Server。

**Backend（Go）**：
- `gateway/internal/config/config.go`：`MCPConfig` 已改为 `Servers []MCPServerConfig` 数组
- `gateway/internal/mcp/client.go`：HTTP JSON-RPC 客户端，支持 Initialize/ListTools/CallTool
- `gateway/internal/mcp/manager.go`（新建）：管理多个 Client，每个独立 Connect/Ready/Tools/Call
- `gateway/internal/api/router_mcp.go`：注册 3 个路由
  - `GET /api/v1/mcp/servers` → 返回所有服务器状态
  - `GET /api/v1/mcp/tools` → 返回所有工具（带 `server_id`）
  - `POST /api/v1/mcp/call` → 按 `server_id` 路由调用
- `gateway/internal/api/router_types.go`：`MCPInfo` 改为 `Servers []MCPServerStatus` + `Tools []mcp.Tool`
- `gateway/internal/api/settings_response.go`：`buildMCPInfo` 遍历 Manager 所有客户端
- `gateway/cmd/server/main.go`：初始化 Manager，ConnectAll() 并行连接

**Frontend（TypeScript）**：

## 五、技术约束

1. **HTTP transport only**：当前 Gateway 只支持 HTTP/SSE MCP transport。网上大部分 MCP Server 默认是 stdio transport，需要通过 `mcp-proxy` 等工具转换后才能接入。
2. **前端必须走 Gateway 入口**：`http://localhost:38471/`，独立前端服务器会导致 SSE 404。
3. **WSL/Docker 内存限制**：WSL2 已限制 4GB，启动大型容器需注意。
4. **Token 认证**：Gateway API 需要 `X-Local-Agent-Token` header 或 `local_agent_token` cookie。Token 存储在 `data/.gateway_token`。
5. **函数行数限制**：所有新增/修改的函数不得超过 30 行。

```powershell
# 查看 Gateway 日志
tail -f logs/gateway.log

# 测试 MCP 工具调用
$headers = @{
  "X-Local-Agent-Token" = (Get-Content data/.gateway_token).Trim()
  "Content-Type" = "application/json"
}
Invoke-RestMethod -Uri "http://127.0.0.1:38471/api/v1/mcp/call" -Method POST -Headers $headers -Body '{"server_id":"rust-mcp-local","name":"datetime","arguments":{}}'

# 查看 MCP 服务器状态
Invoke-RestMethod -Uri "http://127.0.0.1:38471/api/v1/mcp/servers" -Headers @{"X-Local-Agent-Token"=(Get-Content data/.gateway_token).Trim()}

# 重启 Gateway
tasklist | findstr gateway.exe
Stop-Process -Id <PID> -Force
cd gateway; go build -o gateway.exe ./cmd/server
Start-Process gateway/gateway.exe -WindowStyle Hidden
```

# 变更提案

## 为什么做

`BL` 已让明日计划具备日期归属、证据归属与失效判断，但它仍然停留在“展示层”：

1. 到了计划目标日后，这份计划还不能真正接管“今天”。
2. 用户重开今天主线时，时间预算面板不会自动承接昨晚已经生成的计划。
3. 今天执行完成或收尾后，计划也没有被回写成“已接管 / 已执行 / 已收尾”的状态。

## 做什么

1. 给计划补“今日接管状态”和“执行回写状态”。
2. 在进入计划目标日且需重开今天主线时，用这份计划预填今天唯一核心任务。
3. 提交时间预算后，把计划标记为“已接管到今天”。
4. 标记核心任务完成 / 今天收尾后，把执行结果回写到计划状态里。

## 不做什么

1. 不做真正的日历系统同步。
2. 不做跨会话持久化。
3. 不做多日计划链或周计划回写。

## 验收标准

1. 到了计划目标日后，时间预算接管默认可承接计划核心任务。
2. 今日主线接管后，计划卡会显示已接管状态。
3. 今天核心任务完成与收尾后，计划卡会同步显示执行进展。

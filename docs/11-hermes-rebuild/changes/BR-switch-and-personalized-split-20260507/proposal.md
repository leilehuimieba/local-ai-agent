# 变更提案

## 为什么做

`BQ` 已完成计划同步 / 今日接管簇外提，但 `store.ts` 里还保留两簇明显热点：

1. 临时切主线复核、切换、恢复逻辑仍内联在 `store.ts`。
2. 个性化反馈草稿、提交、洞察回写逻辑仍内联在 `store.ts`。

这两簇都已经形成稳定责任边界，继续留在 `store.ts` 会让主线总控 Agent 的状态装配层继续膨胀。

## 做什么

1. 新增 `switch-flow-rules.ts`，外提临时切主线簇。
2. 新增 `personalized-flow-rules.ts`，外提个性化反馈簇。
3. 继续收紧 `store.ts`，只保留 action 装配与默认状态组装。

## 不做什么

1. 不改动主线总控 Agent 的产品规则。
2. 不扩到后端持久化、统计图表或新的 UI 结构。
3. 不做完整 `store.ts` 大拆分，只处理 `switch / personalized` 簇。

## 验收标准

1. `store.ts` 不再直接承载 `switch / personalized` 这两簇派生逻辑。
2. 临时切主线复核、恢复原主线、个性化反馈与洞察相关测试保持通过。
3. 前端定向与全量回归保持通过。

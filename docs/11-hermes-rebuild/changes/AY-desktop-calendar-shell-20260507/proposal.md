# 变更提案

## 背景

- `AX-mainline-control-agent-20260507` 已完成产品定义、迁移边界、桌面插件信息架构、证据规则与切主线规则的文档收口。
- 当前已明确 V1 第一优先是“桌面日历插件常驻闭环”，需要从文档定义进入第一刀可实现入口。
- 若不先落“桌面常驻壳”，后续证据包、概率与切主线都缺少稳定入口承载。
- 对应阶段目标：
  - 自由迭代期的第一实现项，验证“主线总控 Agent”能否真正嵌入日常。

## 目标

- 本次要完成什么：
  - 实现桌面日历插件的轻量常驻壳
  - 固化收缩态的核心展示：当前主目标 + 安全通过概率 / 未知状态
  - 固化展开态的最小入口：今日任务、本周目标、最终目标、晚间证据包入口、补关键证据入口
  - 验证插件可作为开机可见、低打扰、真实可用的总控入口

## 非目标

- 本次明确不做什么：
  - 不实现完整概率引擎
  - 不实现完整晚间证据包逻辑
  - 不实现临时切主线全治理闭环
  - 不在本 change 内完成高度个性化判断
  - 不重写全部旧入口与前端页面

## 验收口径

- 通过标准：
  - 桌面日历插件可轻量常驻
  - 收缩态长期只保留“当前主目标 + 安全通过概率 / 未知状态”
  - 展开态能进入晚间证据包入口与补关键证据入口
  - 48 小时无关键证据时可显示“未知”与“请尽快补充关键证据”
  - 现有旧入口未被破坏

# 变更提案

## 背景

- `BE-time-budget-and-calendar-blocks-20260507` 已完成现实时间预算与今日时间块接管，但主线总控壳仍然停留在“今天该怎么保”。
- 用户真正需要的是：
  - 晚上固定查看后，知道明天该做什么
  - 如果中间临时切过主线，第二天能自动回到原计划优先级
  - 计划不是凭空生成，而是同时基于：
    - 最新关键证据
    - 个性化反馈
    - 现实时间预算
- 当前差最后一层闭环：
  - 当天证据 -> 明日计划
  - 临时主线 -> 次日恢复

## 目标

- 本次要完成什么：
  - 为主线总控壳补上“明日计划生成”最小闭环
  - 允许在晚间证据、个性化反馈、时间预算之后生成明日唯一核心任务与次级补充项
  - 支持“次日恢复原主线优先级”的可见状态
  - 让主线总控壳从“记录与判断”走到“次日行动方案输出”

## 非目标

- 本次明确不做什么：
  - 不接真实系统提醒、通知推送或自动弹窗
  - 不生成复杂的整周排程表
  - 不引入后端持久化、跨设备同步或真实日历写入
  - 不改动关键证据概率逻辑、个性化记录逻辑和时间预算逻辑本身

## 验收口径

- 通过标准：
  - 主线总控壳可见“明日计划”摘要位
  - 用户可手动触发生成明日计划
  - 计划至少包含：
    - 明日唯一核心任务
    - 明日补充任务
    - 计划依据说明
  - 若当前存在临时切主线记录并已恢复，明日计划会优先回到原主线
  - 文档、状态、实现和测试口径一致

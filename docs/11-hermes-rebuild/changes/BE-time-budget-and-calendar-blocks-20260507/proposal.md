# 变更提案

## 背景

- `BD-personalized-roi-followup-20260507` 已完成“先通用、后个性化”的反馈闭环，但仍然停留在“知道哪类任务更适合你”。
- 用户更早已经明确：
  - 这个 Agent 必须与日历/个人行程结合
  - 要能看到最近空余时间
  - 要能把主目标接进现实时间预算，而不是只给抽象建议
- 当前主线总控壳还缺一层关键能力：
  - 当现实时间预算变化时，能先保护主目标最核心部分
  - 当天能明确只有 1 个不可协商核心任务

## 目标

- 本次要完成什么：
  - 为主线总控壳补上“现实时间预算变化 + 今日时间块接管”的最小闭环
  - 允许录入今日可用时间块、现实时间预算变化与今日唯一核心任务
  - 在展开态可见地展示：
    - 今日唯一不可协商核心任务
    - 今日真实可用时间块
    - 当预算不足时的缩量保主线建议
  - 让主线总控壳开始从“只看任务”进入“任务 + 现实时间”的接管模式

## 非目标

- 本次明确不做什么：
  - 不接真实系统日历、Windows 日程或第三方账号同步
  - 不做自动排满全天的复杂排程器
  - 不做周/月级长期时间管理系统
  - 不改关键证据概率规则、临时切主线规则与个性化反馈规则

## 验收口径

- 通过标准：
  - 主线总控壳展开态可见“今日唯一不可协商核心任务”
  - 用户可录入今日可用时间块与现实时间预算变化
  - 录入后能在壳内看到今日时间块列表与预算状态
  - 当可用时间偏低时，会自动给出“先降任务量，保主目标最核心部分”的接管建议
  - 文档、状态、实现和测试口径一致

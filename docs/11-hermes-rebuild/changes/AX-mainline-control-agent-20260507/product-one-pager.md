# 主线总控 Agent 一页纸产品定义

## 产品一句话定义

一个轻量常驻的桌面日历总控 Agent，围绕用户当前最重要的主目标运行，基于关键证据持续判断安全通过概率或达成概率，并通过晚间证据闭环、现实约束重排、临时切主线与自动恢复机制，帮助用户在关键时间窗口里守住主线、持续推进、减少自我糊弄。

## 核心问题

当前用户的主要问题不是没有目标，而是：

1. 主线不收敛，多个重要目标同时抢资源。
2. 计划落不了地，现实时间预算与理想安排经常脱节。
3. 每天会忙，但不知道自己是否真的在推进当前最重要的一仗。
4. 临时事务一旦插入，原主线容易直接断掉。
5. 学习或推进行为有痕迹，但这些痕迹没有稳定转成下一步调整。

## 核心用户

第一核心用户是你自己：长期有多个目标并行、接受被约束、但不接受瞎指挥的人。用户需要的不是泛聊，而是一个先嵌入日常、再越来越懂自己推进模式的常驻总控系统。

## 核心价值

产品只做一件核心事：

> 把当前最重要、最容易被拖散的目标，变成一个持续可见、可校验、可调整、可恢复的主线。

价值具体体现在：

1. 主线收敛：明确当前只打一仗。
2. 证据驱动：不靠感觉推进，靠关键证据更新判断。
3. 现实接管：计划服从真实时间预算与日历约束。
4. 动态恢复：临时切主线后可以自动恢复原主线优先级结构。

## 产品不是什么

它不是：

1. 泛问答聊天机器人。
2. 长期人生规划导师。
3. 价值观讨论搭子。
4. 普通打卡器。
5. 只会提醒的日历工具。
6. 什么目标都想认真推进的大杂烩系统。

## 第一核心场景

V1 第一标准场景是四级冲刺。

选择理由：

1. 有明确截止时间。
2. 失败代价高。
3. 有标准化反馈。
4. 有模考 / 真题这类强关键证据。
5. 最适合验证“系统能否把用户拉进安全通过区”。

在这个场景里，产品负责的不是“让用户看起来在努力”，而是让用户从混乱状态进入更稳、更抗波动、更接近安全通过的推进状态。

## V1 第一优先

V1 第一优先不是最强聊天，也不是最复杂判断，而是桌面日历插件常驻闭环。

如果它不能变成开机就能看到、每天真的会回去面对的东西，再好的督战和概率逻辑也只是对话里的讨论，不是持续系统。

## 核心形态

### 主入口

桌面日历插件，而不是聊天框优先。

### 形态要求

1. 开机启动。
2. 平时极轻量。
3. 重功能按需开启。
4. 可收缩 / 可展开。
5. 默认不以高频打扰维持存在感。

### 收缩态 C 位

1. 当前主目标。
2. 安全通过概率 / 达成概率。

若 48 小时没有关键证据：

1. 概率隐藏或降为“未知”。
2. 同时提示“请尽快补充关键证据”。

## 每日运行方式

### 平稳时期

1. 默认只显示状态，不主动打扰。
2. 用户必须在晚上固定时间主动查看插件。

### 晚间第一动作

先交当天证据包，再谈明天怎么调。

### 每天唯一不可协商核心任务

每天默认只设 1 个不可协商核心任务，避免多任务看起来努力、实际没有一件真正推进。

## 证据包原则

证据包采用“固定核心 + 可变补充型”。

固定核心中最关键的是：

1. 下一步调整。

因为证据不是为了归档，而是为了改变明天。

可变补充按任务类型挂载：

1. 背单词：Anki 数据。
2. 阅读：篇数、分数、耗时、错因。
3. 模考：总分、分项、考试条件可信性。
4. 笔记：关键理解与纠偏点。

## 概率系统原则

桌面中央显示的是当前主目标的安全通过概率 / 达成概率。

更新原则：

1. 只有拿到会改变判断的关键证据，才允许更新。
2. 四级场景下，最高权重关键证据是完整且可信的模拟题 / 真题结果。
3. 单次完整题允许小幅调整。
4. 连续趋势一致时才允许大幅调整。
5. 若 48 小时无关键证据，概率降为“未知”。

## 临时切主线原则

当出现新的紧急且重要事项时，可临时切主线。

规则：

1. 用户先提出。
2. Agent 复核。
3. 用户仍可坚持，但必须记账。
4. 临时目标结束后，自动恢复原主线优先级结构。

## “最了解你”的定义

这里的“最了解你”不是指最会聊人生，而是指：

1. 越来越知道什么安排对你真的有效。
2. 越来越知道你会在哪些环节失速。
3. 越来越知道什么证据最能判断你是否在推进。
4. 越来越知道在现实约束变化时，怎样调整最不容易把你带崩。

## 非核心边界

以下能力可拓展，但不属于当前核心：

1. 长期人生规划。
2. 价值观讨论。
3. 泛问答。
4. 日常陪聊。
5. 无明确结果压力的长期自我探索。

## V1 成功标准

V1 成功，不是因为它看起来很智能，而是因为：

1. 你真的会开机看到它。
2. 你真的会在晚上固定回去对账。
3. 你真的能围绕一个主目标持续推进。
4. 你不会因为临时事务彻底丢掉原主线。
5. 关键证据会真正改变中间那个概率数字。
6. 每次关键证据进入后，系统都能把你推向下一步调整。

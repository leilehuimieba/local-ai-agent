# 临时切主线与自动恢复规则

## 目标

定义在长期主线存在时，如何处理新出现的紧急且重要事项，避免目标混战，同时保证切换有依据、可记账、可恢复。

## 基本原则

1. 常态下只认真推进一个主目标
2. 出现新的紧急且重要事项时，可以临时切主线
3. 临时切主线不是双主目标并行，而是短窗战时接管

## 触发条件

默认规则：

1. 只要出现新的紧急且重要事项，就可以提起临时切主线

典型例子：

1. 下周算法考试
2. 短期内必须完成、无法事后补救的工作或事务
3. 临近出差前必须补齐的关键准备

## 裁决流程

1. 用户先提出要切主线
2. Agent 复核是否属于紧急且重要
3. 若通过复核，切主线生效
4. 若未通过复核，用户仍可坚持，但必须记账

## 记账规则

若用户坚持执行未通过复核的切主线：

1. 系统记录为一次“偏离复核意见”的主线切换
2. 原主目标成功率或推进稳定性应同步体现代价
3. 该行为需在后续复盘中可追溯

## 切换后的目标结构

1. 临时目标升为当前主目标
2. 原主目标降级
3. 默认不允许“双主目标”并行认真推进

## 自动恢复规则

1. 临时主线结束后，自动恢复原主线
2. 恢复的是原计划优先级结构，不是机械恢复旧日程
3. 恢复后仍需服从当前现实时间预算

## 与时间预算的关系

1. 即使原主线来自更强长期目标，也必须服从现实时间预算
2. 若时间骤减，恢复后默认优先保短期收益最高的任务

## 与次目标的关系

1. 临时切主线期间，次目标默认继续降级
2. 不允许次目标与临时主目标争抢黄金时间

## 回退与复盘

1. 切主线必须可复盘
2. 结束后要能说明：
   - 为什么切
   - 切换期间牺牲了什么
   - 恢复后主线怎样接回

# 桌面日历插件常驻闭环信息架构

## 目标

定义桌面日历插件作为 V1 主入口时的收缩态、展开态、晚间入口与补证入口，确保插件先成为日常总控壳，再承载后续督战与概率逻辑。

## 设计原则

1. 轻量常驻，默认低打扰。
2. 收缩态只保留最关键的主线判断。
3. 展开态提供最小闭环所需的行动与证据入口。
4. 先显示状态，再进入行动，不把复杂聊天放在插件入口层。

## 收缩态

### C 位长期展示

1. 当前主目标
2. 安全通过概率 / 达成概率

### 次级状态

1. 风险颜色等级：绿 / 黄 / 橙 / 红
2. 概率趋势：上升 / 持平 / 下降
3. 若 48 小时无关键证据，显示“未知”

### 当概率为未知时

1. 显示“请尽快补充关键证据”
2. 点击后默认进入“录入最新模拟题 / 真题结果”

## 展开态

### 第一屏

1. 当前主目标
2. 当前安全通过概率 / 达成概率
3. 今日唯一不可协商核心任务
4. 今晚证据包状态：未提交 / 可补交 / 已提交

### 第二屏

1. 本周目标（可展开）
2. 最终目标（可展开）
3. 当前次目标与其状态
4. 当前风险说明与下一步建议

### 第三屏

1. 日历中的真实可用时间块
2. 最近关键证据时间
3. 最近一次模块级调整方向
4. 是否存在临时切主线记录

## 晚间固定查看入口

### 触发原则

1. 默认不主动弹窗
2. 用户需在晚上固定时间主动回插件

### 晚间入口第一动作

1. 先交当天证据包
2. 再看状态变化与明日调整

## 证据包入口

### 固定核心字段

1. 今天围绕主目标做了什么
2. 可验证结果
3. 失败或卡点
4. 下一步调整

### 可变补充字段

1. Anki 数据
2. 阅读 / 听力 / 词汇专项结果
3. 模考 / 真题分数与考试条件信息
4. 笔记或错因摘要

## 补证入口

### 默认入口

1. 收缩态下点击“请尽快补充关键证据”
2. 直接进入模拟题 / 真题结果录入

### 备用入口

1. 展开态中的“补关键证据”按钮
2. 晚间证据包界面中的“补录关键证据”

## 风险升级显示

### 黄

1. 仅颜色提醒
2. 不强制重排

### 橙

1. 要求尽快补证
2. 提供调整建议

### 红

1. 先要求提交最近现实约束证据
2. 再决定是否重排、缩量、切主线

## 非目标

1. 不在插件收缩态展示大段聊天记录
2. 不把全部知识、日志、记忆结果都直接塞进首页
3. 不把插件做成常驻高资源大应用

# 变更提案

## 背景

- 当前项目已完成 Hermes 总路线 A~H 与阶段 I 收口，进入自由迭代期。
- 现有产品口径仍偏“本地智能体能力集合”，需要收束为“主线总控 Agent”。
- 本次变更要解决的问题：
  - 把产品核心从“会做很多事”收敛为“持续推进一个主目标”
  - 把桌面入口从聊天优先改为日历 / 状态优先
  - 把证据、概率、风险、临时切主线纳入统一治理
  - 在不破坏现有必要能力的前提下完成迁移
- 对应阶段目标：
  - 自由迭代期的产品语义重定向与迁移收口

## 目标

- 本次要完成什么：
  - 固化《主线总控 Agent》的一页纸产品定义
  - 明确第一核心场景为“四级冲刺”
  - 明确桌面日历插件常驻闭环为 V1 入口
  - 明确证据包、概率更新、临时切主线、自动恢复等核心规则
  - 明确旧能力的保留、降级、迁移、淘汰边界

## 非目标

- 本次明确不做什么：
  - 不新开独立仓库或独立项目
  - 不立即重写全部运行时与前端
  - 不把产品改造成长期人生规划 / 价值观讨论型 agent
  - 不把所有现有能力都提升为核心能力
  - 不在本 change 内直接实现全部功能代码

## 验收口径

- 通过标准：
  - 新产品定义、核心场景、非核心边界已落到正式文档
  - 迁移边界与兼容策略已明确，且不破坏现有必要能力
  - `current-state.md`、`changes/INDEX.md` 已同步切换到本 change
  - 后续实现可据此拆分为可执行任务与验证项

## 当前收口结论

  - `D:/newwork/本地智能体/docs/11-hermes-rebuild/changes/AX-mainline-control-agent-20260507/product-one-pager.md`
- 当前产品收束结论：

  - 第一核心场景：四级冲刺
  - V1 第一优先：桌面日历插件常驻闭环
  - 非核心边界：长期人生规划 / 价值观讨论 / 泛问答 / 日常陪聊

# 证据包与概率更新规则

## 目标

定义什么证据有资格改变主目标判断，什么证据只能作为弱参考，以及概率何时更新、何时失效、何时降为未知。

## 证据分层

### 强关键证据

1. 完整且可信的模拟题 / 真题结果
2. 会显著改变主目标安全通过判断的现实时间预算变化

### 中强证据

1. 模块级专项测试结果
2. 连续性的 Anki 关键数据
3. 可验证的阅读 / 听力阶段结果

### 弱参考证据

1. 非完整考试条件下的练习结果
2. 一般学习笔记
3. 主观状态汇报

## 四级场景下的最高权重证据

最高权重证据默认是完整且可信的模拟题 / 真题结果。

### 可信性门槛

要成为可直接改动概率的强关键证据，必须满足：

1. 有做题日期
2. 有总用时
3. 明确是否完整按考试条件完成
4. 先录总分
5. 必须当场补全分项得分

### 非完整考试条件结果

1. 允许记录
2. 允许作为弱参考存在
3. 不得直接改动安全通过概率

## 概率更新原则

1. 只有拿到会改变判断的关键证据，才允许更新概率
2. 一般学习痕迹或普通打卡，不足以激活概率更新
3. 概率更新以强关键证据优先，弱证据只能辅助解释

## 模考 / 真题结果的更新力度

1. 单次完整题：允许小幅调整概率
2. 连续趋势一致：允许大幅调整概率
3. 连续趋势所需样本数：由剩余时间决定
   - 时间宽裕时，更谨慎
   - 临近考试时，更敏捷

## 概率失效规则

1. 若 48 小时内无新的关键证据，明确概率隐藏或降为“未知”
2. 此时不继续沿用旧概率数字冒充当前判断
3. 收缩态必须同时提示“请尽快补充关键证据”

## 概率恢复规则

1. 只有补入关键证据，才允许重新激活概率
2. 四级场景下，默认补证入口直达“录入最新模拟题 / 真题结果”

## 概率更新后的默认动作

1. 先更新安全通过概率
2. 再生成下一步调整建议
3. 调整建议默认先到模块级，而不是直接给大量碎任务

## 晚间证据包规则

### 固定核心

1. 今天围绕主目标做了什么
2. 可验证结果
3. 失败信息
4. 下一步调整

### 为什么“下一步调整”最关键

因为证据包不是为了归档，而是为了直接改变第二天或下一阶段的安排。

## 补交规则

1. 晚间未提交证据包时，先允许补交
2. 补交窗口截止到次日中午前
3. 到点仍未补交，由 Agent 判断：
   - 先补昨天
   - 还是直接保今天
4. 裁决默认优先保护短期收益最高项

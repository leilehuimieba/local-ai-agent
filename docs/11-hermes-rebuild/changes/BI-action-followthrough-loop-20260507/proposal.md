# 变更提案

## 背景

- `BH-next-step-entry-priority-20260507` 已经能告诉用户“现在先点哪个按钮”，但做完一步之后，系统还不会自动把用户送到下一步。
- 当前仍存在一个断点：
  - 晚间证据提交后，下一步是补关键证据还是生成明日计划，要靠用户重新看卡片
  - 关键证据更新后，下一步是否该立刻生成明日计划，也还没有明确的动作联动
- 这意味着主壳已经有了“第一步优先级”，但还没有真正形成“连续动作流”。

## 目标

- 本次要完成什么：
  - 在关键动作完成后自动重判下一步动作
  - 为主壳增加“刚完成什么 / 下一步是什么”的连续引导提示
  - 让晚间证据提交、关键证据更新、明日计划生成三者形成顺滑衔接

## 非目标

- 本次明确不做什么：
  - 不接真实系统通知或自动弹窗
  - 不做跨天持久化
  - 不改动现有概率计算模型
  - 不引入复杂任务编排历史系统

## 验收口径

- 通过标准：
  - 提交晚间证据后，主壳会自动重判并提示下一步
  - 更新关键证据后，主壳会自动引导到明日计划或时间预算接管
  - 生成明日计划后，主壳会明确说明该计划是否基于最新关键证据
  - 文档、实现与测试口径一致

# 变更提案

## 背景

- `BC-capability-classification-and-entry-degrade-20260507` 已完成主入口叙事切换，主线总控 Agent 已正式接管首页语义。
- 但用户最早提出的核心要求之一还没有被兑现：Agent 需要逐步成为“最了解我、但不能自信乱判断”的那个总控。
- 对应产品原则已经明确：
  - 先通用、后个性化
  - 证据驱动，不靠感觉贴标签
  - 只保留会改变后续安排的关键反馈

## 目标

- 本次要完成什么：
  - 为主线总控壳补上“个性化推进反馈”最小闭环
  - 记录不同任务类型的完成情况与短期收益反馈
  - 给出不抢主入口、但可见的“更适合你的推进方式”提示
  - 让后续计划调整开始基于历史反馈，而不是只基于单次主观判断

## 非目标

- 本次明确不做什么：
  - 不做长期人格画像或价值观建模
  - 不接真实日历、Anki、外部插件或后端同步
  - 不做复杂推荐引擎、概率学习模型或自动排程器
  - 不改当前关键证据概率规则与临时切主线规则

## 验收口径

- 通过标准：
  - 主线总控壳中出现“更适合你的推进方式”展示位
  - 用户可以记录一次任务反馈：任务类型 / 是否核心 / 是否完成 / 是否带来短期收益 / 结果备注
  - 记录提交后，主壳会基于历史记录给出更易完成项、短期收益最高项、阻力偏高项的可见提示
  - 文档、状态、实现和测试口径一致

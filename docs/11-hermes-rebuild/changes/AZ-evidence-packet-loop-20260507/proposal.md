# 变更提案

## 背景

- `AY-desktop-calendar-shell-20260507` 已完成桌面常驻壳第一轮实现，主线总控入口已具备基础承载能力。
- 目前插件只有“晚间证据”入口，没有真正的证据包闭环，无法形成“晚上回插件先对账”的产品主链。
- 对应阶段目标：
  - 把主线总控 Agent 从“可见入口”推进到“可提交证据、可产出下一步调整”的第一闭环。

## 目标

- 本次要完成什么：
  - 实现晚间证据包最小闭环
  - 提供固定核心字段与可提交表单
  - 支持在主线总控插件中打开晚间证据入口
  - 提交后能在本地状态层形成“已提交”反馈
  - 为后续 BA 概率更新与证据治理提供前端承载

## 非目标

- 本次明确不做什么：
  - 不实现真正模考驱动的概率引擎
  - 不实现次日中午前补交的完整时间调度器
  - 不接真实后端持久化协议
  - 不实现临时切主线与恢复逻辑

## 验收口径

- 通过标准：
  - 用户可从 `MainlineShell` 进入晚间证据包
  - 可填写并提交一份最小证据包
  - 提交后界面状态能反映“已提交”
  - 证据包包含“下一步调整”这一核心字段
  - 现有 AY 壳与其他视图未被破坏

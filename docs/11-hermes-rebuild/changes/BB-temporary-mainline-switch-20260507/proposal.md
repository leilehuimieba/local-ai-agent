# 变更提案

## 背景

- `BA-key-evidence-and-probability-20260507` 已完成关键证据、概率更新与模块级调整的最小闭环。
- 当前桌面总控壳已经会判断“该不该继续当前主线”，但还不会处理现实里突然插入的紧急且重要事项。
- 对应阶段目标：
  - 把主线总控 Agent 从“会判断”推进到“会战时接管并自动恢复”的第三闭环。

## 目标

- 本次要完成什么：
  - 实现临时切主线申请入口
  - 实现“紧急且重要”复核逻辑
  - 支持未通过复核但用户坚持时记账后执行
  - 实现临时主线生效后的原主线降级
  - 实现临时主线结束后自动恢复原计划优先级结构

## 非目标

- 本次明确不做什么：
  - 不接真实日历块与外部调度器
  - 不做复杂多主线并行调度
  - 不做跨天自动定时恢复器
  - 不做后端持久化或复盘报表导出

## 验收口径

- 通过标准：
  - 用户可从 `MainlineShell` 发起一次临时切主线
  - 满足紧急且重要的事项可通过复核并切换生效
  - 不满足复核但用户坚持时，会留下记账信息后执行
  - 临时主线生效后，原主线降级且收缩态切换到临时目标
  - 点击恢复后，系统会自动恢复原计划优先级结构

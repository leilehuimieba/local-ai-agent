# 变更提案

## 背景

- 本次变更要解决的问题：MCP 工具已经接入运行时，但前端仍缺少一个能让人看懂、筛选、审计和快速判断风险的运营入口。
- 对应阶段目标：自由迭代期里，把 MCP 从“能用”推进到“可观测、可运营、可收口”。

## 目标

- 本次要完成什么：在设置页建立 MCP 工具的可观测视图，至少能看到工具清单、风险等级、allowlist 命中状态和审计字段。

## 非目标

- 本次明确不做什么：不重写 MCP 协议，不改 Runtime 工具分发主链路，不新增浏览器自动化能力，不做完整安全控制台。

## 验收口径

- 通过标准：前端能清晰展示 MCP 工具的风险、allowlist、审计字段和基础筛选结果，并留下构建或人工验收证据。

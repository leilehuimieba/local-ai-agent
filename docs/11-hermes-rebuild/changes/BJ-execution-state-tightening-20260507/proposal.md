# 变更提案

## 为什么做

`BI` 已经把“做完一步后自动切到下一步动作”跑通，但当前主线总控壳仍有一个明显缺口：
系统知道“下一步是什么”，却还不知道“今天是否已经进入执行态、核心任务是否已经完成、今天是否应该收尾”。

这会导致两个问题：

1. 主按钮区虽然有推荐动作，但其他动作仍然同等显眼，执行时容易再次分心。
2. 计划与执行之间没有回写，系统无法在“今天正在做 / 已做完 / 今天到此为止”之间切换。

## 做什么

1. 新增执行态状态结构，显式记录：
   - 是否已进入今天执行态
   - 今天核心任务是否完成
   - 今天是否已收尾
2. 主按钮区自动高亮当前动作，弱化非当前动作。
3. 时间预算接管后进入执行态。
4. 支持“标记今天核心任务完成”与“进入今天收尾”回写。

## 不做什么

1. 不做跨天持久化。
2. 不做真实提醒、通知或系统级日历同步。
3. 不重写概率规则、临时切主线规则或个性化 ROI 规则。

## 验收标准

1. 当前推荐动作在主按钮区有明确高亮，非当前动作被弱化。
2. 提交时间预算后，系统进入“正在执行今天核心任务”。
3. 标记核心任务完成后，系统切到“进入今天收尾”。
4. 进入今天收尾后，系统不再继续强推其他动作。

# 变更提案

## 背景

- `AZ-evidence-packet-loop-20260507` 已完成晚间证据包最小闭环，主线总控壳已经具备“晚上先对账”的入口。
- 当前仍缺少真正会改变判断的关键证据闭环，插件还不能把“模考 / 真题结果”转成安全通过概率与模块级调整建议。
- 对应阶段目标：
  - 把主线总控 Agent 从“可提交证据”推进到“关键证据可更新判断”的第二闭环。

## 目标

- 本次要完成什么：
  - 实现模考 / 真题结果的关键证据录入入口
  - 实现关键证据可信性门槛校验
  - 支持完整结果更新安全通过概率
  - 支持非完整考试条件结果只记录、不改概率
  - 在概率更新后给出模块级调整建议
  - 支持 48 小时无关键证据时收缩态降为“未知”

## 非目标

- 本次明确不做什么：
  - 不接后端持久化或真实日历调度器
  - 不做复杂的长期个性化概率模型
  - 不实现临时切主线与自动恢复治理
  - 不把普通打卡、笔记、主观状态直接纳入概率更新

## 验收口径

- 通过标准：
  - 用户可从 `MainlineShell` 进入“补关键证据”录入入口
  - 完整且可信的模考 / 真题结果可直接更新安全通过概率
  - 非完整考试条件结果可记录，但不会直接改动概率
  - 48 小时无关键证据时，收缩态显示“未知”并提示补证
  - 概率更新后能展示一条持续到下一次关键证据出现的模块级调整建议

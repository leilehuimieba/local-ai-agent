# 变更提案

## 为什么做

`BM` 已经让明日计划在目标日接管今天，并能回写执行结果，但当前主壳里“今天计划”仍只是明日计划卡里的附属字段：

1. 用户还看不到独立的“今天计划”视角。
2. 晚间证据包没有直接对账“今天是否按计划完成”。
3. `mainline-shell.tsx` 已超过 600 行热点红线，需要在本刀中顺手拆分，避免继续堆叠。

## 做什么

1. 独立出“今日计划卡”，只展示今天真实在执行的计划。
2. 晚间证据区增加“今日计划对账提示”，明确今天是否按计划推进。
3. 在本 change 中完成 `mainline-shell.tsx` 的最小职责拆分备案与落地。

## 不做什么

1. 不做跨会话计划历史。
2. 不做完整周视图。
3. 不做真实系统提醒与通知。

## 验收标准

1. 进入计划目标日并接管后，主壳可独立显示“今日计划卡”。
2. 晚间证据区能显示“今天是否按计划完成”的对账提示。
3. `mainline-shell.tsx` 不再继续扩张，核心卡片拆到独立文件。

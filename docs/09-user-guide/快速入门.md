# 本地智能体 — 快速入门

## 1. 安装与启动

### 环境要求
- Windows 10/11
- Go 1.22+（Gateway 编译）
- Rust 1.80+（Runtime 编译）
- Node.js 20+（前端构建）

### 首次启动
1. 双击项目根目录的 `start.bat`
2. 脚本会自动检查依赖、编译 Gateway、构建前端
3. 启动完成后，浏览器自动打开 `http://127.0.0.1:38471/`

### 手动启动（开发者）
```powershell
# 1. 构建前端
cd frontend
npm run build

# 2. 编译 Gateway
cd ../gateway
go build -o server.exe ./cmd/server

# 3. 启动 Gateway（前端静态文件由 Gateway 托管）
./server.exe
```

## 2. 首次对话

### 发送消息
1. 在底部输入框输入任务描述
2. 按 `Enter` 发送（`Shift+Enter` 换行）
3. 等待 AI 响应，消息会逐字流式显示

### 快捷提示
点击输入框上方的快捷按钮可快速发送常见任务：
- 查询数据库
- 总结文档
- 编写代码
- 分析数据

---

## 3. 核心功能

### 搜索消息
- 点击消息列表顶部的 🔍 图标
- 输入关键词，匹配的消息会高亮显示
- 使用 ↑↓ 按钮在匹配项之间跳转

### 导出会话
- 点击输入框左侧的 📥 按钮
- 自动下载 `.md` 文件，包含完整对话记录

### 取消运行
- 运行中会出现「取消」按钮
- 点击后终止当前任务

### 编辑重发
- 点击用户消息右上角的「编辑」
- 修改内容后发送，该消息及之后的所有消息会被替换

## 5. 设置

点击顶部「设置」标签进入配置页面：

### 模型配置
- **Model**：选择使用的大模型（默认 DeepSeek V4 Pro）
- **Providers**：配置 API Key、测试连通性、保存/应用/移除

### 工作区
- 切换当前工作区
- 查看授权目录

### 风险设置
- 目录访问确认开关
- 风险等级显示开关

### 诊断
- 一键运行健康检查
- 检查仓库状态、Runtime 状态、服务商连通性

## 6. 常见问题

### Q: 页面显示 401 Unauthorized
**A**: Gateway 首次启动时会生成本地 Token。刷新页面即可自动获取授权。

### Q: AI 长时间无响应
**A**:
1. 检查 Gateway 和 Runtime 进程是否在运行
2. 检查设置 → 诊断中的服务商连通性
3. 检查网络是否可访问 `api.deepseek.com`

### Q: 刷新页面后消息丢失
**A**: 消息保存在浏览器 localStorage 中（最多 200 条）。如果使用了隐私模式或清除了浏览器数据，历史消息会丢失。

### Q: 如何切换回之前的会话
**A**: 在右侧 TASK CONTEXT 面板的「Recent Runs」中点击对应的运行记录即可恢复。
